## Install with Python

Python 3.11 or newer is required; Python 3.12 is recommended. Use a dedicated environment.

```bash
conda create -n anylabeling python=3.12
conda activate anylabeling
python -m pip install anylabeling
anylabeling
```

For NVIDIA CUDA on Linux or Windows, install `anylabeling-gpu` in a fresh environment. Apple Silicon users can install `anylabeling[macos]` for CoreML. See [Installation](/docs/installation) and [Hardware Acceleration](/docs/gpu) for complete setup instructions.
